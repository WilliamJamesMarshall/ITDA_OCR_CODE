# 검증셋 000001-000352

이 디렉터리는 `상품사진입니다`의 `000001`부터 `000352`까지를 대상으로 만든 1차 수동 검증셋이다. OCR은 날짜 후보 위치를 찾는 보조 수단으로만 사용했고, 최종 값은 원본 또는 확대 검수 시트로 다시 확인했다.

## 파일

- `validation_000001_000352.csv`: 전체 352장 라벨
- `needs_review_000001_000352.csv`: 두 번째 검수자가 확인해야 하는 11장만 분리한 큐
- `ocr_candidates_000001_000352.jsonl`: OCR 후보 문자열, 위치, 신뢰도
- `review_sheets/`: 8장 단위 확대 검수 시트 44개
- `tools/`: 후보 추출, 검수 시트 생성, 라벨 CSV 생성 스크립트

## 라벨 규칙

- 소비기한이 명확하면 `YYYY-MM-DD`로 정규화한다.
- 제조일과 소비기한이 함께 있으면 소비기한 또는 `까지`에 해당하는 종료일을 선택한다.
- 다른 상품이나 홍보 문구의 날짜는 대상 상품의 소비기한으로 사용하지 않는다.
- 소비기한이 실제로 보이지 않으면 `NONE`으로 둔다.
- 날짜 순서나 가려진 숫자를 단정할 수 없으면 원문 또는 잠정 후보를 보존하고 `needs_review`로 둔다.
- `needs_review` 행은 두 번째 검수가 끝나기 전까지 일반 정답 평가에서 제외한다.

## 현재 요약

- 전체: 352장
- `manual`: 341장
- `needs_review`: 11장
- 난이도: easy 95장, medium 243장, hard 14장
- 소비기한 없음: 3장 (`000028`, `000078`, `000232`)

오류 유형은 한 이미지에 여러 개가 적용될 수 있다. 주요 분포는 점자형·잉크젯형 인쇄 166장, 정상 95장, 반사·흐림·저대비 76장, 두 자리 연도 59장, 제조일자·소비기한 동시 48장, 다양한 구분자 42장, 전화번호·바코드 오인 위험 28장, 회전·기울어짐 13장이다.

## 두 번째 검수 절차

두 번째 검수자는 `needs_review_000001_000352.csv`의 11개 이미지와 원본을 대조한다. 합의된 값은 `tools/write_validation_labels.py`의 `DATE_ROWS`에 반영하고 해당 ID를 `NEEDS_REVIEW`에서 제거한 뒤 스크립트를 다시 실행한다. 모든 합의가 끝나 `needs_review_000001_000352.csv`가 헤더만 남으면 2인 검수 완료다.

현재 재검토 대상은 `000004`, `000024`, `000032`, `000043`, `000106`, `000118`, `000120`, `000143`, `000157`, `000190`, `000263`이다. 각 잠정 판단 근거는 CSV의 `비고`에 기록했다.
