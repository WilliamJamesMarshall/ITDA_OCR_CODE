# 4단계 — 상품 그룹 기반 분할 준비

상태: **진행 중, 공식 분할 미확정**.

## 수행 결과

- 현재 2,610개 원본 이미지 SHA-256 재검사: 변경 0건, 정확한 중복 해시 0개.
- 기존 group_id는 2,610개의 개별 SHA 그룹이다. 사용자 주석 승인을 같은 상품이 하나로 통합되었다는 증거로 간주하지 않았다.
- 0/90/180/270도 pHash, HSV 색상 히스토그램, 축소 공간 배치 특징을 계산했다. 유사 후보는 6,529쌍이다. 높은 유사도는 동일 상품 확률이나 확정 판정이 아니다.
- 비교 화면: http://127.0.0.1:8768 — 같은 그룹/다른 그룹/보류 판단을 검수자·시각과 함께 별도 저장한다. 기존 승인 주석과 공식 fold는 수정하지 않는다.
- 시각 후보를 찾지 못한 이미지도 단독 상품으로 자동 확정하지 않는다. 최종 그룹 검수에는 후보 밖의 동일 상품과 연속 촬영도 포함해야 한다.

## 분할 드라이런

`../01_splits/draft/`에 `split_manifest.csv`, `fold_01.csv`~`fold_05_final.csv`, `split_summary.json`을 생성했다. 이들은 **학습·평가에 사용할 공식 파일이 아니다**.

- seed: 20260911. 알고리즘: 그룹 단위 크기 및 날짜유형×난이도×출처 층화 greedy v1.
- 현재 드라이런 크기: 각 522장, 합계 2,610장.
- 현재 SHA 그룹/해시 교집합 0, 기존 705장의 fold 5 포함 0.
- 모든 평가 CSV는 정답을 포함하지 않는다. fold 5 CSV에는 이미지 ID와 경로만 있다.
- 이미지별 정답으로 층화 유형을 만들었으므로 이 드라이런을 사전 미열람 holdout 선정이라고 주장하지 않는다. 최종 선정·잠금은 그룹 확정 이후 별도로 기록한다.

## 아직 남은 작업

1. 상품·포장 버전·연속 촬영·파생본 그룹의 시각 검수 및 그룹 통합.
2. 후보 판정의 전이적 그룹 연결과 서로 다른 상품 판정 간 충돌 해결, 전체 이미지의 그룹 검수 완료 기록.
3. 승인 그룹 기준 705장 배제 범위를 확장하고 분할 재생성. 정확히 522장이 불가능하면 그룹을 쪼개지 않고 크기 변경을 승인받는다.
4. 최종 그룹/해시/ID 교집합 검증 후 공식 manifest와 알고리즘·seed·입력 해시 동결.

현재 pair_decisions는 원본 주석을 자동 변경하지 않는다. group_review_template.json은 최종 그룹 검수 입력 양식이며 아직 승인된 결과가 아니다. 후보 검수만으로 4단계 완료를 선언하지 않는다.

재생성은 `python -m scripts.prepare_group_splits`, 원본 해시 확인은 `python -m scripts.verify_split_inputs`를 사용한다. 기존 사용자 판정이 있으면 해당 판정 및 검수 파일을 보존하여 통합해야 한다.
