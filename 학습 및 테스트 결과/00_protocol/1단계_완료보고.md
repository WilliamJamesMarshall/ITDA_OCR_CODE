# 1단계 데이터·정답지 정비 완료

157번 정답을 `2027-07-08`로 확정하고, 네 XLSX의 기존 전체 미인식 정답 38개 셀을 `NONE`으로 수정했다. OCR 공통 출력·완료 행 저장·평가기·관련 테스트와 현재 실행 계약에도 `NONE`을 반영했다. 부분 날짜는 알려진 필드를 보존한다.

XLSX는 원래 위치에 저장했다. 라벨 상태는 최종 날짜 승인 의미의 `approved`로 채웠다. 상품사진의 난이도·조건은 기존 메타데이터를 계승했으며, 추가수집의 판독 난이도는 근거가 없어 `unassessed`로 명시했다. 사람 주석 검수 시 이를 확정한다. 원문과 polygon은 아직 승인하지 않았다.

추가수집 재번호화로 낡아진 학습 매핑 364건, 추가수집 manifest 364건, 테스트 manifest 364건, 주석 키 364건을 SHA-256으로 복구했다. 원래 파일과 해시는 `data/originals/`, `data/original_hashes.json`에 보존했다.

2단계는 `data/annotation_review_queue.jsonl`의 2,610장 목록과 `data/source_annotation_candidates.jsonl`의 404개 후보로 바로 시작할 수 있다. 상품사진 원문·영역 구축, 추가수집 후보 전수 사람 검수, 상품 그룹과 난이도·조건 확정을 수행한 뒤 fold와 영구 내부 validation을 생성한다. 현재 group_id는 동일 SHA 자산 수준이므로 상품 그룹 확정값으로 사용하면 안 된다.

현재 완료 판정은 `stage1_readiness.json`, 코드·XLSX 확인은 `stage1_verification.json`, 데이터 규칙은 `stage1_data_protocol.md`, 정본 이미지·라벨은 `dataset_inventory.json`과 `data/training_labels.jsonl`에 있다. 현재 모델 학습 승인 건수는 0이며 이는 다음 2단계의 원문·영역 승인이 남아 있다는 뜻이다.
