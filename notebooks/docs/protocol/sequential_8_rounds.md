## 승인과 실행 순서

현재 모델 테스트 → 추론 종료 → 별도 scorer 채점 → 보고서 → 사용자 피드백과 명시적 학습 승인
→ 원본 대응 확인 → 중복 제거·누적 개발 데이터 편입 → 학습·내부 validation 선정
→ export·파이프라인 로딩 확인 → 선정 모델로 다음 테스트.
1회 시작은 준비 완료 보고 후 사용자 시작 지시가 있어야 한다.
8회 승인 후 마지막 학습·export로 종료하며 9회 테스트는 없다.
최종 학습 모델의 별도 독립 테스트 성적은 존재하지 않는다.

승인에는 실제 사용자 지시, 원문 참조, 시간대 포함 시각, 회차, 범위, 피드백,
보고서·manifest·코드·모델 해시를 기록한다. 소프트웨어가 승인 원문을 생성하지 않는다.
목표 달성 여부와 무관하게 보고하며 자동 승인하지 않는다.
최초 평가 기록은 덮어쓰지 않는다. 피드백에 따른 변경은 별도 재평가 이력과 새 승인에 연결한다.
JSON gate는 실수 방지 장치이며 OS 접근통제 또는 사용자 신원 증명 체계가 아니다.

## 원본과 그룹

동일 이미지 연결은 SHA-256, 증강본 연결은 출처·파생 관계와 검토 근거를 요구한다.
번호만으로 전체를 연결하지 않는다. 1회 216쌍도 SHA-256으로 검증한다.
연결 불명확 항목은 검토 대기이며 해당 회차의 원본 편입을 차단한다.
증강 테스트 파일은 optimizer/validation에 직접 입력하지 않는다.
원본에서 생성된 승인 OCR crop은 인식기 입력으로 허용한다.
원본 학습 설정의 온라인 RecAug/RecConAug는 기존 계약으로 유지한다.
동일 원본은 같은 회차 및 후속 회차에 중복 편입하지 않는다.

사용자 승인 회차의 원본만 누적 개발 데이터에 편입한다.
optimizer_train과 inner_validation은 검증된 group_id 단위 약 90:10으로 분할한다.
같은 상품·연속 촬영·파생 관계는 같은 그룹이며 기존 역할은 영구 보존한다.
한 번 validation인 그룹은 이후 optimizer에 들어가지 않는다.
이미지 수 비율보다 그룹 무결성을 우선하며 양쪽에 유효 crop이 없으면 학습을 차단한다.

## 학습 계약

CPU 전용, Python 3.10, 4스레드, seed=20260911.
매 회차 동일한 승인 초기 체크포인트에서 누적 원본으로 재학습한다.
직전 회차 모델에서 이어 학습하지 않는다. 초기 가중치·문자 사전·runtime 해시는 고정한다.
75 epoch 상한과 기존 학습률·optimizer·전처리 설정을 보존한다.
매 epoch 전체 내부 validation crop을 평가한다.
NFC, 앞뒤 공백 제거, 영문 대소문자 통일, 줄바꿈 통일만 정규화한다.
체크포인트는 문자열 완전일치율 → 낮은 micro CER → 높은 NED 유사도 → 이른 epoch 순이다.
5 epoch 연속 개선이 없으면 중단한다. PaddleOCR best_accuracy는 정식 선정 근거가 아니다.
날짜 줄 인식기가 1차 대상이다. 검출기 학습은 별도 준비 대상이며 자동으로 추가하지 않는다.
검출기 선정 시 기존 recall 보호, Hmean 및 기존 동률 규칙을 유지한다.

## 평가 독립성·출력

추론 프로세스에 정답과 원본 대응표를 전달하지 않는다.
제출용 사본의 predict.ipynb를 실행한 후 별도 명령으로 scorer를 실행한다.
추론 사본의 준비 복사·패키지 설치와 별도 채점 시간은 노트북 실행시간에서 제외한다.
프로세스 시작과 전체 노트북 실행을 측정하고, 이미지별 p50/p95는 pipeline summary에서 가져온다.
출력 열은 image_id,year,month,day,final_date. 미인식 final_date는 NONE.
157번 확정 정답 2027-07-08과 추가수집 364장 사용자 검수 이력을 유지한다.

번호순 회차 사이의 동일 원본·상품 그룹 노출은 허용된 배치 구성의 특성이며 독립 평가로 주장하지 않는다.
기존 705장 개발 노출과 과거 공개 정답 이력을 보존한다.
전체, 원본/증강, 이전 학습 원본, 미노출 확인, 노출 불명확 지표를 구분한다.
다음 회차 테스트 정답이나 성적을 checkpoint 선정에 사용하지 않는다.

## 실행 전 확인

보존 기준선과 8개 manifest 검사, 원본 대응·그룹 검토, 승인 차단, 누적 분할,
학습 preflight, 회귀검사, 정답 없는 제출 사본 검증을 수행한다.
새 회차 이미지를 준비 과정에서 OCR 추론하거나 학습하지 않는다. 상품 그룹용 시각 검토는 허용한다.
생성한 합성 이미지로 epoch·내부 validation·저장·early stopping을 검증할 수 있으며 그 모델은 정식 모델에 반영하지 않는다.
현재 미해결 원본 대응·공식 환경·실제 학습 및 export의 검증 범위는 준비 보고서에 명시한다.
정본은 이 파일이다. 이전 execution_policy 및 실행계획 문서는 과거 기록이다.
