# 2단계 OCR 학습 주석 구축 착수 결과

추가수집 364장의 XLSX 최종 날짜가 사용자의 전수 육안 검수 결과라는 사실을 모든 해당 이미지의 `final_date_review`에 기록했다. 최종 날짜는 승인 상태로 유지한다.

`annotation_schema.json`에 날짜 줄/블록, 표제, 원문, 역할, 필드 가시성, 가려진 문자, 구분자·시각·로트, 품질, 그룹, 검수자·승인 상태를 정의했다. 역할·날짜 순서나 가려진 문자는 최종 날짜에서 추정해 주입하지 않았다.

검수 화면은 http://127.0.0.1:8765 에 실행 중이다. 이미지 확대, 다각형 추가·꼭짓점 이동, 원문·속성 입력, 표제 연결, 임시 저장과 사람 승인을 지원한다. 서버를 종료한 뒤 재시작하는 방법은 `검수_안내.md`에 있다.

검수자·영역 확인·역할·필드 가시성·품질·그룹 확인이 빠진 승인을 거절한다. 날짜가 NONE이라는 이유만으로 검출 음성으로 승인하지 않는다. 승인 후 수정하면 재승인이 필요하며 이전 레코드는 history에 보존한다. 원본 이미지 SHA, 원본 ID와 최종 날짜는 고정한다.

승인된 레코드만 crop/원문 인식 풀과 전체 이미지/polygon 검출 풀로 내보내는 기능을 구현했다. 판독 불가 줄은 인식 라벨에서 제외하되 날짜 영역 검출에는 포함할 수 있다. 아직 실제 승인 레코드가 없어 학습용 정본은 생성하지 않았다. 임시 테스트 데이터로 승인·내보내기·승인 해제를 검증했다.

확인 결과: 기존 1단계 동결 해시가 전부 유지됐고, 최종 날짜 2,610건과 원천 날짜 줄 문자열 404건이 변경되지 않았다. 현재 2,610건은 주석 검수 대기이며 `stage_2_complete=false`다. 상품사진 나머지 2,245장은 원문·영역 후보 생성 또는 수동 주석이 남아 있다.

다음 실제 작업은 추가수집 후보의 사진 대조·원문/역할/영역 확인과 상품사진 주석 구축이다. 그룹을 검수한 뒤 고정 정책에 따라 fold·영구 내부 validation을 만들고, 문자 사전 호환 검사를 거쳐 실제 학습 목록을 구성한다.
