## 사용자 동선

로컬 검수 화면: <http://127.0.0.1:8765>

1. 사진 전체와 잘린 영역, 원문·역할·품질·그룹 초안을 확인합니다.
2. 맞으면 **초안이 맞음 · 승인하고 다음**을 한 번 누릅니다. 반복 확인란을 따로 채울 필요가 없습니다.
3. 틀린 부분은 **틀린 부분 편집 · 선택 영역 상세**에서 수정합니다. 폴리곤 꼭짓점을 드래그할 수 있습니다.
4. 어려운 사진은 **보류하고 다음**으로 편집 내용을 저장하고 넘깁니다.

상단 **초안 준비 상태**로 정상 초안과 수정 필요 초안을 나눌 수 있습니다. 검수자 표시 기본값은 로컬 사용자를 뜻하는 ‘사용자’이며, 원하는 이름을 한 번 지정하면 브라우저에 기억합니다. 날짜 없는 사진으로 표시하는 것은 별도의 명시적 확인이 필요합니다.

## 사용한 근거와 한계

- 상품사진: 새 CPU OCR 1,103장 + 기존 로컬 CPU OCR 1,143장.
- 추가수집: 기존 영역/원문 364장, 사용자가 승인한 최종 날짜 유지.
- 날짜 누락 590장에 기존 다른 해상도 OCR을 추가 대조했습니다.
- 그 후 누락 382장에 픽셀 기반 줄 제안과 한글/영문 인식기를 적용하여 111장에서 후보를 추가했습니다.
- 기존 OCR은 당시 이미지 SHA-256을 기록하지 않았습니다. 현재 파일 연결, 현재 SHA-256, OCR 크기를 확인하고 EXIF/리사이즈 좌표를 역변환했지만, 역사적 파일 동일성이 증명됐다고 간주하지 않습니다. 출처 한계는 영역별 provenance에 남겼습니다.
- 일반 설명문·전화번호·성분 비율로 보이는 OCR은 참고 영역으로 분리했습니다. 잘못 분리된 날짜는 화면에서 날짜 후보로 가져올 수 있습니다.
- 품질 측정은 날짜 영역의 높이·대비·흐림 휴리스틱입니다. 반사·곡면·번짐·점 인쇄 등의 시각 검토를 대체하지 않습니다.
- 상품 그룹은 파일 동일성 기반의 임시 초안이며, 유사 사진 후보를 별도 표시합니다. 자동으로 상품 그룹을 병합하지 않았습니다.
