# 원본 수 비례 1~5회 누적 학습 승인 계획

사용자 요청: “각 회차가 학습오차에 기여하는 총 비중을 각 회차의 이미지 데이터 개수 가중평균으로 조정하여 누적학습을 다시 수행하려고 한다. 1회차부터 5회차까지의 누적학습을 다시 수행하는 계획을 정리해서 가져와.”

아래 계획 보고 직후 사용자 실행 지시: “시작해.” 원문과 이 문서 SHA를 새 release에 연결한다.

- 대상 원본 수 216:500:500:394:500, 분모 2,110. 가중치는 10.2369668% / 23.6966825% / 23.6966825% / 18.6729858% / 23.6966825%.
- 기존 승인 pool을 유지한다. optimizer 원본 194/499/488/379/481, crop 201/577/571/892/1075. 총 원본 2,041장, crop 3,316개. 검증 24원본/25crop, 격리 28원본, 적합 crop 없음 17원본은 optimizer 제외를 유지한다.
- 각 회차의 학습 가능한 원본에 동등한 계수를 부여하고, 각 원본 계수를 그 원본의 crop에 나눈다. q_crop=(회차 대상 원본 수/2110)/(회차 학습 가능 원본 수)/(해당 원본 crop 수).
- 각 crop을 1회만 사용한다. 반복 추출·자료 축소 없음. 손실은 CTC crop별 손실 + NRTR crop별 유효 문자 평균(기존 0.1 label smoothing 유지). 후자는 기존 배치 전체 문자 평균에서 의도적으로 변경된다.
- 미니배치 손실은 sum(3316*q_crop*crop_loss)/8. 잔여 4개도 고정 분모 8로 계산하여 표본당 과대 반영하지 않는다. 회차 계수의 합은 고정하지만 실제 gradient 비율이나 실제 손실값 비율을 보장하지 않는다.
- 시작 모델은 직전 퇴행 후보가 아니라 기존 채택 모델 epoch_001.pdparams, SHA 07f23a2059d05d9977969e1f4a8742974376a5e1e47e28f23af7f23f13c611d9.
- 1 epoch, batch 8, 415 steps, LR 5e-6, Adam/Cosine, seed 20260911, BN 통계 고정, CPU 0~3·4스레드. 실시간 증강 없음. 저장 증강 1,106장 제외. 한국어 인식기만 학습한다.
- 원본 공급원 C:/ITDA_OCR_CODE/학습대상데이터. 원본·주석·정답·crop·그룹 역할 SHA를 실행 전후 확인한다. 기존 최종 정답 정정과 crop 전사는 구분하며 임의 수정하지 않는다.
- 기존 로컬 온라인 승인 워크플로를 유지하며 외부 업로드·관리자 창·방화벽 변경은 하지 않는다. 기존 실행/공유 lock을 확인하고 중복 실행하지 않는다.
- 시작 및 epoch1 내부 crop 검증을 비교한다. 기존 비퇴행 gate 실패 시 후보 보존, 추가 epoch/export 자동 진행 금지. 통과 시 별도 후보 export만 허용한다.
- 내부 25 crop는 1·3회만 포함한다. 전체 2,110장 정확도 및 4·5회 성능의 증거가 아니다. 검증 상품 그룹을 학습으로 옮기지 않는다.
- 전체 이미지 테스트, 6회, 공용 weights 교체, 단계 종료, 모델 채택, commit/push는 승인 범위에 없다.
- 코드/보고서는 저장소 작업 브랜치에, 불변 실행 자료는 별도 workspace에 보존한다. 과거 보고서를 덮어쓰지 않는다.
- 예상: 준비 45~75분, 학습·내부 검증 105~120분, 결과 확인·조건부 export·보고서 10~20분. 총 2시간 40분~3시간 35분. 실제 처리 속도로 갱신한다.
