## 코드 개선 확인 범위

karpathy-guidelines에 따라 재현된 실패와 필요한 코드만 변경했다.

1. 일본어 `製造`/`製造年月日` 제조일 역할 지원. `製造者`/`製造元`/`製造所` 업체 표기를 날짜 역할로 오인하지 않도록 검사했다.
2. `negative-context`/`expiry-not-printed`가 된 결과의 오래된 부분 날짜 필드를 철회한다.
3. 두 날짜·두 표제의 정렬·간격이 맞고 날짜 및 한쪽 표제의 신뢰도가 높은 경우, 약한 반대쪽 표제를 같은 블록으로 연결한다. 일반적인 최근접 표제 판정은 완화하지 않는다.

AMLC000911(출력 별칭 AMLT000953)의 저장 selector 입력 12개에서 `2021-01-07` → `2021-02-05`를 확인했다. 이것은 회복 일정·이전 출력 유지까지 포함한 전수 평가가 아닌 선택 함수 재생이다. AMLC000853의 저장 OCR에는 필요한 일본어 표제가 제대로 읽히지 않아 규칙 추가만으로 과거 출력이 해결됐다고 주장하지 않는다. 검출/잘림/숫자 인식 실패는 이 코드만으로 복구할 수 없으며 실제 새 모델 효과는 보류 해제 후 평가해야 한다.

Notebook 내장 소스를 생성기로 동기화했다. 수정 후 단위 검사 584개 통과(24.921초). 실제 원본 1~5회 테스트는 실행하지 않았다. 원래 예산·타임아웃·정답 없는 후보 수용 제한을 유지한다.

## 보존과 시간

첫 준비본 v1은 고정 사본의 원본 루트 경로 처리를 보완하기 위해 optimizer 시작 전에 폐기 표시하고 보존했다. v2가 유일한 실제 학습 작업이다. 실패한 학습을 성공 처리하거나 이미 끝난 회차를 다시 테스트한 것이 아니다.

초기 학습 속도는 batch당 약 15초, 전체 학습·내부 검증·export 예상 약 105~115분이다. 준비 당시 80~100분 추정을 실제 속도로 갱신했다. 학습 시간에는 notebook 테스트의 2,400초 강제 종료 기준을 적용하지 않는다. 최종 시간·메모리·checkpoint·내부 검증 통과 여부는 실제 종료 후 보고한다.

내부 검증 25 crop는 1·3회에 속하며 4·5회 성능을 대표하지 않는다. 95% 달성이나 새 모델 채택 근거로 이 내부 지표만 사용하지 않는다. 향후 2,110장 평가는 누적 개발 성적이며 독립 최종 성적이 아니다.
