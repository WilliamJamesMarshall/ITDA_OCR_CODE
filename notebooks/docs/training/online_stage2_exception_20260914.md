# 2·3회 개발 재시험의 온라인 실행 예외

2026-09-14 실제 사용자 지시:

> 남은 작업 시작해. 2회차 및 3회차 테스트는 오프라인으로 하지 않아도 된다. 오프라인에서 돌아가는 거 확인했으니까 관리자 실행 승인요청화면 띄울 필요 없이 온라인으로 2회차 및 3회차의 테스트를 실행해. 남은 작업 완료한 후에.

범위는 남은 구조 개선 사전검증과 이어지는 2·3회 500장 개발 재시험이다. 관리자 실행이나 방화벽 변경 없이 온라인 환경을 허용한다. 외부 서비스에 이미지를 전송하거나 외부 OCR을 사용하지 않으며, 고정된 로컬 모델을 그대로 사용한다.

개발 기록·시작 승인·job·runtime에 `network_mode=online`을 명시하고 `offline_verified=false`로 기록한다. 기존 오프라인 기본값과 과거 검증 기록을 변경하지 않는다. 이전 코드의 오프라인 성공을 새 내장 노트북의 오프라인 검증으로 표시하지 않는다.

P2+E2 각 4스레드, 입력/코드/모델 해시, 원본 대응, 정답 보존, 기존 결과 불변, 메모리·시간 검사는 유지한다. 먼저 사전검증을 통과한 고정 사본에 실제 위 지시를 연결한다. 학습·공용 가중치 반영·다음 단계 승인은 포함되지 않는다.

## 1,600초 구조 개선 후속 재시험

사용자는 오답 분석 후 “500건 전체 처리시간은 1,600초까지 늘어나도” 된다고 명시했고,
이어 “수정작업 시작해. 그 작업을 마친 후, 2회차 및 3회차 테스트를 관리자 실행 승인요청화면 띄울 필요 없이 온라인으로 실행하고 결과보고서를 정리해서 가져와”라고 지시했다.

이 후속 개발 재시험은 회차별 전체 노트북 목표를 1,600초로 기록한다. non-CONFIG 예산 1,570초와 그 안의 30초 출력 여유를 사용해 nbconvert 시작·종료 및 변동 여유를 남긴다. 2,400초 강제 종료는 유지한다. 옛 실행의 1,500초 판정·기록을 바꾸지 않고, 다른 회차에 이 예외를 자동 적용하지 않는다.
실제 지시, 분석 보고서, 변경된 코드·노트북·불변 모델·이미지 목록 해시를 새 authorization에 연결한다. 상태 정본의 최초 보고서와 완료 단계는 변경하지 않는다.
