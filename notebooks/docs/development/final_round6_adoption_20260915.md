# 6회차 최종실험 종료 및 누적 학습 가중치 채택

사용자 지시: “이 가중치를 채택하고 6회차 최종실험을 종료하도록 한다. 이 가중치를 GitHub Repository에 커밋-push해.”

이번 누적 학습의 epoch_001 한국어 인식기를 채택하고 6회차 최종실험을 종료한다. 성능 관문의 자동 통과가 아니라, 미달과 퇴행을 보고받은 사용자의 명시적 채택이다. 추가 학습·추가 테스트를 자동 시작하지 않는다.

- 학습: 1~6회 승인 크롭 4,390개, 1 epoch, 549 optimizer steps, 고정 내부 검증 25개.
- 학습 checkpoint SHA-256: `4f701656898a0a73fecaa5a6fdc9b14883b2cc811d6a57b2b3277a449f5991af`.
- 추론 가중치 SHA-256: `88518d3485b9d1c7fa570b8936584a2f2e01fc0ea796777b0b1f14e36f8da033`.
- 평가한 추론 export 3파일을 그대로 배포한다. 검출기·영문 인식기·추론 코드는 변경하지 않는다.
- [고정 Release](https://github.com/WilliamJamesMarshall/ITDA_OCR_CODE/releases/tag/adopted-recognizer-final-round6-20260915)에 추론 파일을 배포하고 download_weights.sh에서 URL과 SHA-256을 고정한다. 학습 checkpoint와 optimizer 상태는 로컬에 보존하며 배포하지 않는다.
- 이전 채택 모델·manifest·다운로드 스크립트는 로컬 `final-model-adoption-20260915-v1/previous`와 기존 Git 이력·Release에 보존한다.
