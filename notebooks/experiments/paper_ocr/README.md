이 폴더는 개발 실험 실행·검증 도구다. 공용 추론 코드/모델, 최초 회차 결과와 다음 단계 상태는 변경하지 않는다.

실행 도중 프로젝트가 `grouped-6-originals-v1`로 이관되었다. 최초 `full-01`은 당시 고정된

## 성공 기준

각 회차 500장에 대해 연·월·일 1,500필드 중 1,425필드 이상 정답, 전체 노트북 실행 1,600초 이하.
미처리/실패 이미지는 분모에 남긴다. 기존 정답 필드의 손실도 별도로 기록한다.
2·3회는 반복 노출된 개발 자료이며 독립 테스트 성능으로 해석하지 않는다.

## 이번에 구현한 것

- 날짜 구분자 `:`와 독립된 시각 `HH:MM`을 구분한다.
- `28.04.1912:58`에서 뒤의 시각을 연도 `1912`로 흡수하지 않는다.
- OCR 재인식 방식이 달라도 원본 좌표로 가까운 날짜 순서 표기를 연결한다. 좌표가 없거나 다른 날짜가 더 가까우면 적용하지 않는다.
- 잘린 월 단위 crop이 같은 영역의 기존 완전한 날짜에서 일 정보를 삭제하지 않도록 한다.
- 개발용 노트북 실행기의 제한을 1,600초로 설정한다. 네이티브 OCR 호출의 내부 취소를 보장하지 않으며, 외부 실행기가 제한 초과 시 자신의 프로세스 트리를 종료하고 실패로 기록한다. 정상 실행은 1,570초 내부 예산에서 출력 여유 30초를 둔다.

일반적인 '과거 관측 전부 유지' 변경은 전체 기록에서 추가 이익이 없어서 제거했다.
표본 ID/정답을 추론 로직에 넣거나 제조일과 소비기한의 필드를 합성하지 않았다.

## 논문과의 관계

[Expiration-date OCR 연구](https://www.mdpi.com/1999-4893/18/5/286)의 도메인 날짜 형식 처리와
[인식 신뢰도 보정 연구](https://arxiv.org/abs/2012.12643)의 불확실성 분리 관점을 참고한 프로젝트 구현이다.
이번 수정은 논문 모델의 재현이나 학습된 신뢰도 보정기가 아니다.

[STRAug](https://arxiv.org/abs/2108.06949),
[PP-OCRv5](https://arxiv.org/abs/2603.24373),
[SVTRv2](https://arxiv.org/abs/2411.15858)의 증강·데이터 선택·비율 보존 학습은 후속 단계다.
현재 crop 파일이 존재한다는 사실만으로 학습 승인이나 상품 그룹 분리가 완료됐다고 판단하지 않는다.

## 학습 준비 상태

2·3회 대응 원본 1,000건의 상품 그룹 검토가 미완료다.
현 회차 crop 1,155개 + 이전 승인 crop 223개, 총 1,378개의 파일 해시는 정상이다.
원본·주석 연결 오류는 없으나 crop별 필드 라벨은 없다.
상품 그룹 확정 후 **내부 검증으로 배정된 crop에 대해서만** 연·월·일 정답 검토가 필수다.
`groups.draft.json`과 `crops.draft.json`은 승인 파일이 아니며 optimizer 입력으로 사용하지 않는다.
