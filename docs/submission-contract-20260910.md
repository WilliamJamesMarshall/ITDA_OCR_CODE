# 제출·평가 계약 정비 결과 — 2026-09-10

2026-09-11 정정: 사용자가 전달한 학술제 공지에 따라 전체 누락의 `final_date`는 `NONE`이다. 아래 출력·평가 설명에는 현재 계약을 반영했다. 검증 수치와 이후 단계 설명은 2026-09-10 당시 기록이며 최신 데이터 정비 상태는 `학습 및 테스트 결과/00_protocol/stage1_readiness.json`을 따른다.

## 완료 범위

구조적 진단 보고서의 **0단계: 제출·평가 계약 정비**를 기능 단위로 완료했다. 정상 결과, 이미지 실패, 완료 행 체크포인트, 타임아웃 부분 저장, 평가 및 관련 테스트를 함께 처리했다. karpathy-guidelines에 따라 기존 인식/역할/순서 규칙은 변경하지 않았고 미확정 제출 형식을 추가하지 않았다.

### 출력과 저장

- 전체 누락의 최종 문자열은 `NONE`, 개별 year/month/day 열은 각각 `NONE`이다. 내부 `DateSelection.final_date = None`은 유지한다.
- 저장 함수도 공통 직렬화를 사용한다. 세 필드가 모두 NONE이면 최종 문자열은 NONE이고, 그 외에는 세 필드를 하이픈으로 연결한다. 구형 완료 행의 `NONE-NONE-NONE`도 저장 시 정규화된다.
- 기존 부분 형식 `NONE-MM-DD`와 `YYYY-MM-NONE`은 그대로 보존한다. `YYYY-NONE-NONE` 등 새 부분 형식은 제출 세칙 미확정으로 추가하지 않았다. 숫자/필드를 추측하는 로직은 넣지 않았다.
- 이미지 실패 원인은 별도 failures에 남는다. 타임아웃으로 처리되지 않은 이미지는 가짜 전체 누락 행을 만들지 않는다. 열 이름·순서 및 노트북 환경변수 계약은 유지한다.

### 평가

- 과거 라벨과 결과의 `NONE-NONE-NONE`은 `NONE`과 의미상 동일하게 비교한다. 과거 파일은 수정하지 않는다.
- 내부 95% 목표는 날짜 전체 일치율 그대로다. 연·월·일 각각에 전체 일치, 값이 있는 정답의 정답/오독/미출력/평가 불가, 정답에 값이 없는 경우의 NONE 일치/값 과잉 출력/평가 불가를 집계한다.
- 실행 실패, 잘못된 날짜 문자열, 누락 행은 필드 정답으로도 세지 않는다. 잘못된 날짜의 일부를 이 평가 단계에서 임의 복원하지 않는다. 각 비율의 분모를 기록하며 분모가 없으면 null이다.
- 공식 부분점수 배점은 미확정이므로 `official_partial_score`는 null이다. 필드 평균을 공식 점수 또는 내부 95% 달성으로 표시하지 않는다.
- 의미상 정확도와 제출 형식 준수율은 별도다. 구형 NONE-NONE-NONE, 열 순서 오류, 필드 불일치가 있거나 형식을 확인하지 못한 결과는 결합 합격으로 처리하지 않는다.
