## 3번 — Food Packaging OCR Dataset

공식 배포는 Mendeley Data의 버전 2이며 2026-06-15 공개, 라이선스는 CC BY 4.0이다. 소개에서는 실물 식품 포장의 문자 검출·인식 자료라고 설명한다. [공식 페이지](https://data.mendeley.com/datasets/3cpx2fmn3r/2)

공개 파일 API로 ZIP 1개, **2,561,540,317바이트(약 2.56GB)**를 확인했다. HTTP Range를 이용해 필요한 부분만 읽었으며 ZIP 전체는 받지 않았다. 배포자가 표시한 SHA-256은 `74b288e6da78c29b31812e3e23ff3fe19b634a3b0e659dea8b86b8de0a04e5fd`다. 전체 파일을 받지 않았으므로 이 해시를 직접 검증한 것은 아니다. [파일 목록 API](https://data.mendeley.com/public-api/datasets/3cpx2fmn3r/files?folder_id=root&version=2)

아래는 ZIP 목차와 내부 README에서 직접 확인한 수량이다.

| 구분 | train | valid | test | 합계 |
| --- | ---: | ---: | ---: | ---: |
| det: 상품 장면 이미지 | 8,736 | 1,092 | 1,092 | 10,920 |
| rec: 문자 인식 이미지 | 8,736 | 1,092 | 1,092 | 10,920 |

전체는 JPG 21,840개와 TXT 7개다. **21,840장을 독립적인 상품 사진 수로 세면 안 된다.** 직접 확인한 `rec/train/images/0004.jpg`는 `det/train/images/0007.jpg`의 날짜 부분을 잘라낸 55×16픽셀 이미지였다. 날짜 크롭에는 포장 문맥이 없어 최종 소비기한 선택 평가의 입력으로 그대로 쓰기 어렵다. [배포 ZIP](https://data.mendeley.com/public-files/datasets/3cpx2fmn3r/files/59dbd51c-2251-4ce9-9830-e948c2726ada/file_downloaded)

검출 라벨은 파일명과 JSON 목록으로 구성된다. 전체 10,920행의 영역 속성은 `transcription`과 `points`뿐이며, 제조일·소비기한을 구분하는 역할 라벨은 없었다. 인식 라벨은 파일명과 문자 전사다. 따라서 프로젝트의 `final_date` 정답은 별도로 검수해야 한다.

전체 검출 라벨을 검색한 결과는 다음과 같다. 실제 이미지의 전수 판독 결과가 아니라 **라벨 문자열 검색 결과**다.

| 항목 | train | valid | test | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 한글 음절이 전사된 이미지 | 12 | 1 | 3 | 16 |
| 숫자 날짜 패턴이 있는 이미지 | 373 | 43 | 45 | 461 |
| 기한 관련 키워드가 있는 이미지 | 448 | 65 | 33 | 546 |
| 위 두 날짜 조건 중 하나 이상 충족 | 688 | 87 | 68 | 843 |

숫자 패턴은 구분자로 나뉜 숫자 세 묶음, 키워드는 `best before`, `use by`, `expiry`, `expiration`, `exp`를 사용했다. **843개는 수동 검토 후보이며, 소비기한 사진의 정확한 개수나 전체 탐지율이 아니다.** 영문 월·분리된 숫자·전사 누락은 놓칠 수 있고, 용량 표기는 잘못 잡힐 수 있다. 실제 후보 `train/0012.jpg`와 `train/0041.jpg`에는 용량 관련 문자열이 날짜 형태로 잡혔다. 한글 16개 역시 한국 상품 수를 의미하지 않는다. [로컬 집계 근거](C:/ITDA_OCR_CODE/.codex-tmp/source-review-20260911/mendeley_label_audit.json)

상품 사진 5개를 내려받아 크기를 확인했으며 긴 변은 모두 400픽셀이었다. 그중 우유 음료 전면과 뒤집힌 요거트 뚜껑 사진을 직접 보았다. 요거트에는 USE BY와 점 인쇄 날짜가 있고, 라벨은 `24/06/2021`로 전사한다. 현재 데이터와 가까운 사례가 존재하지만 작은 날짜의 해상도가 낮다. 이 해상도 특성을 전체 10,920개에 일반화하지는 않는다. 인식 라벨 일부에서는 문자 인코딩 깨짐도 관찰되었다.

**판정:** 영문 날짜·회전·작은 글씨에 대한 보충용으로 적합하다. 한국어 소비기한 사례를 대량 확보하는 주력 출처로 삼기에는 근거가 부족하다. 먼저 843개 후보와 영문 월 표기 후보를 확인하고, 날짜 역할과 정답을 수동으로 확정하는 것이 효율적이다. 전체 출처와 재가공 이력, 기존 사진과의 중복 여부도 편입 전에 확인한다.

## 4번 — Open Food Facts

공식 AWS 배포에는 사용자 업로드 이미지와 Google Cloud Vision으로 얻은 기존 OCR 결과가 함께 있다. `openfoodfacts-images` 버킷의 `data/` 아래에 바코드·이미지 ID별로 저장하며 사진은 JPG, OCR 결과는 JSON.GZ다. 월 단위 동기화로 최근 업로드가 빠질 수 있다. [공식 AWS 안내](https://openfoodfacts.github.io/openfoodfacts-server/api/aws-images-dataset/)

공식 문서의 예시 상품 `4012359114303`의 원본 `1.jpg`와 `1.json.gz`를 실제로 받았다. 사진은 식품 포장 전면이고, OCR에는 전사와 문자 좌표가 들어 있었다. 이 사진에서는 소비기한 표시를 확인하지 못했다. **사진과 OCR이 존재해도 소비기한 평가에 바로 쓸 수 있다는 뜻은 아니다.** 이는 배포 경로를 확인한 단일 예시이며 날짜 가시율의 추정 표본은 아니다. [예시 이미지](https://openfoodfacts-images.s3.eu-west-3.amazonaws.com/data/401/235/911/4303/1.jpg), [예시 OCR](https://openfoodfacts-images.s3.eu-west-3.amazonaws.com/data/401/235/911/4303/1.json.gz)

추천 수집 절차는 다음과 같다.

1. 제품 API 또는 공식 데이터 덤프로 국내 판매 식품, 원하는 브랜드·카테고리의 후보를 정한다. 국내 판매 여부와 한국 제조 여부는 구분한다.
2. 대표 전면 이미지뿐 아니라 제품의 전체 이미지 목록을 확인한다. 포장 측면·바닥·봉합부·뒷면에 날짜가 있을 수 있다.
3. 제공되는 OCR 결과에서 기한 문구와 날짜 후보를 검색한다. 이는 후보 선별에만 사용하고, OCR에서 날짜를 못 찾은 표본도 일부 확인해 누락 유형을 파악한다.
4. 날짜 후보가 있는 원본 고해상도 사진을 받아 실제 소비기한·제조일·로트 번호를 사람이 구분한다. 제품 메타데이터의 기한을 특정 사진의 정답으로 자동 복사하지 않는다.
5. 같은 실물의 사진·크롭·리사이즈를 묶어 관리하고 기존 테스트셋과 중복을 제거한다.

다량 다운로드는 공식 AWS 경로가 권장되며, 검색 API를 반복 호출해 전체를 긁는 방식은 피한다. 이번 국내 판매 제품 검색 API 시도는 HTTP 503으로 실패했으므로 **한국 관련 사진 수와 날짜 포함 비율은 확인하지 못했다.** 공식 문서는 전체 요청량 제한에서도 503이 발생할 수 있다고 설명하나, 이번 응답의 원인을 확정한 것은 아니다. [이미지 수집 안내](https://openfoodfacts.github.io/openfoodfacts-server/api/how-to-download-images/), [API 운영 안내](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/)

이미지 라이선스는 공식 링크 기준 **CC BY-SA 3.0**, 데이터베이스는 **ODbL**, 개별 데이터 내용은 **Database Contents License**다. 출처·라이선스·변경 이력을 보존하고, 이미지 가공본이나 데이터베이스 재배포 시 해당 조건을 적용해야 한다. 한 가지 라이선스로 전체 출처를 덮어쓰지 않는다. [공식 라이선스 안내](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/tutorials/license-be-on-the-legal-side/), [이미지 라이선스](https://creativecommons.org/licenses/by-sa/3.0/deed.en)

**판정:** 장기적으로 다양한 상품을 계속 수집하기에는 가장 유망하다. 다만 소비기한 전용 정답셋이 아니므로 선별·라벨링 작업량이 크고, 실제 확보량은 시범 수집으로 측정해야 한다. 제공된 OCR 결과를 이용하면 별도 유료 OCR 호출 없이 후보 검색을 시작할 수 있지만, 기존 OCR을 정답으로 간주해서는 안 된다.

## 6번 — AI-Hub 의약품·화장품 패키징 OCR

공식 설명은 직접 촬영한 제품 포장 이미지와 JSON OCR 라벨 **50,000쌍**이다. 통계 이미지의 상위 구분은 의약품 20,000, 화장품 30,000이다. 의약품 쪽 세부 표에는 **건강기능식품**도 포함되어 있어 현재 상품 사진과 가까운 부분을 찾을 가능성이 있다. 다만 세부 표의 수량과 상위 합계에 불일치가 있어 건강기능식품의 실제 파일 수는 다운로드 목록으로 확인해야 한다. 50,000쌍을 서로 다른 제품 50,000개로 해석하지 않는다. [데이터 상세](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=633), [공식 통계 이미지](https://aihub.or.kr/web-nas/aihub21/files/editor/2022/06/7b3f021563c643fd9b0e7ed146527368.png)

공개 이미지 예시는 화장품 포장의 긴 설명문을 문자 영역별로 표시한 것이다. 공개 스키마의 핵심은 `annotations.polygon.text`, `points`, `bbox`다. `images.class`는 의약품 등 이미지 종류를 나타내며 소비기한 역할 라벨과 다르다. **공개 예시에서 소비기한·제조일을 구분하는 전용 의미 필드는 확인되지 않았다.** 원본 JSON 전수 검사는 하지 않았으므로 전체에 없다고 단정하지 않는다. `data_captured`는 촬영 시각이므로 상품 기한 정답으로 쓰면 안 된다. [이미지 예시](https://aihub.or.kr/web-nas/aihub21/files/editor/2022/06/293c373955204f4b8dddd3c9103123fe.png), [라벨 스키마](https://aihub.or.kr/web-nas/aihub21/files/editor/2022/06/f8d4f9cbc4f24906890c0ee2976d6fb7.png)

접근 절차는 본인 확인·사용 목적을 포함한 신청 후 다운로드 승인을 받고 공식 API/Shell을 사용하는 방식이다. 상세 페이지는 내국인만 신청 가능하다고 안내한다. Windows에서는 API 다운로드 파일의 분할 압축 처리를 위해 WSL 사용을 안내한다. 이번 설명서·활용가이드 링크 직접 요청은 “정상적인 접근이 아닙니다” 응답을 반환했으며, 실제 데이터 다운로드나 계정 신청은 수행하지 않았다. 파일 용량·기한 포함 사진 수·현재 계정의 승인 상태는 미확인이다. [다운로드 안내](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=633)

이용정책은 영리·비영리 연구개발 활용을 안내하면서도 데이터는 **“인공지능 학습모델의 학습용으로만”** 사용할 수 있다고 명시한다. 따라서 현재처럼 독립 테스트셋에 편입하는 용도까지 허용되는지는 제공처의 확인이 필요하다. 또한 NIA 사업 결과임을 표시해야 하며, 미승인 제3자 제공·열람과 국외 반출에는 별도 제한이 있다. 공개 데이터라는 이유로 팀원에게 자유롭게 재배포할 수 있다고 가정하지 않는다. 이는 공개 정책의 범위를 정리한 것이며, 평가 사용이 금지된다고 확정하는 판단은 아니다. [AI-Hub 이용정책](https://aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)

**판정:** 건강기능식품 부분을 우선 살펴볼 조건부 후보다. 한글 포장 문자에는 유용하지만 화장품·전문의약품까지 현재 식품 중심 테스트셋에 통째로 넣는 것은 적절하지 않다. 건강기능식품의 날짜가 보이는 원본과 역할 정답을 확보하고, 평가 용도에 대한 이용 범위를 확인한 다음 편입을 판단한다.

## 편입 전 공통 기준

신규량은 상품 이미지와 크롭을 구분하고 기존 3,716개와의 중복을 제거한 뒤 센다. 최종 정답은 사람이 원본에서 확인하고 불명확 사례는 재검수 대상으로 둔다. 수집 사유는 점 인쇄·반사·회전·복수 날짜 등 보완할 오류 유형과 연결한다. 이번에는 검토용 표본과 메타데이터만 확보했으며 기존 사진, 번호, 라벨, 코드 및 `.gitignore`는 변경하지 않았다.
