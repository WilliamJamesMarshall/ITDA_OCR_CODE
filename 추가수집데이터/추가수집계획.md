# ExpDate 추가수집 계획

## 1. 수집 목적

- 상품 포장에 인쇄된 소비기한·유통기한의 위치 검출과 문자열 인식을 위한 학습 데이터 보강
- 기존 데이터와 물리적으로 분리해 원본 보존 및 중복 검사를 가능하게 함
- 원본 파일명, 학습/평가 구분, 라벨, 체크섬을 보존해 재현 가능한 데이터셋으로 관리

## 2. 수집 출처와 이용 조건

- 데이터셋: ExpDate (Korea Institute of Science and Technology)
- 공식 페이지: https://felizang.github.io/expdate/index_expdate.html
- 라이선스: CC BY 4.0
- 사용 시 원 저작자와 논문을 표시하고, 데이터를 수정한 경우 수정 사실을 명시해야 함

| --- | --- | ---: | --- |

이미지 해상도와 JPEG 인코딩은 공식 배포본을 그대로 보존했다. 이미지 루트는 기존 입력 폴더와 같은 평면 구조이며, 부가 정보는 `metadata` 폴더에 분리했다.

## 4. 메타데이터

- `metadata/source_manifest.csv`: 새 파일명, 원본 ZIP·경로·파일명, 데이터 분할, 해상도, SHA-256, 라이선스, 출처 URL
- `metadata/annotations.json`: 새 파일명으로 키를 변경한 ExpDate 원본 라벨
- `metadata/source_archives.json`: 다운로드한 공식 ZIP의 크기와 SHA-256

## 5. 학습 투입 전 처리 계획

1. 무결성 검사
   - 이미지 13,625장이 모두 열리는지 검사
   - 번호 누락·중복, 라벨 누락, 라벨 해상도와 실제 해상도 불일치 검사
   - 매니페스트 SHA-256과 실제 파일 해시 대조
2. 기존 데이터와 중복 제거
   - 기존 `상품사진입니다`의 초기 3,352장에는 ExpDate 원본 또는 재인코딩·회전본이 포함되어 있음
   - SHA-256 완전 일치뿐 아니라 pHash/특징점으로 재인코딩·회전 중복도 그룹화
   - 같은 원본 계열 이미지는 반드시 하나의 train/validation/test 분할에만 배치
3. 라벨 변환
   - ExpDate의 `date`, `due mark`, `production mark`, `code mark` 박스와 transcription을 현재 OCR 학습 포맷으로 변환
   - 소비기한 정답과 제조일·로트번호를 구분할 수 없는 표본은 별도 검수 큐로 이동
4. 도메인 균형화
   - 실제 이미지와 합성 이미지의 학습 샘플링 비율을 조절해 합성 데이터 편향 방지
   - 한국어 표기, 점자형 인쇄, 레이저 각인, 곡면·반사 포장 표본을 우선 보강
5. 추가 실사 수집
   - 공개 데이터로 부족한 최신 한국 상품은 매장·물류 파트너 또는 크라우드 수집으로 300~500개의 서로 다른 상품/로트를 확보
   - 촬영자·매장·상품·촬영 세션 ID를 함께 기록해 평가 누수를 방지
6. 증강 정책
   - 회전, 원근, 흐림, 반사광, 저조도, JPEG 열화를 학습 분할에만 적용
   - 증강본은 별도 원천 이미지로 집계하지 않고 `parent_image_id`로 원본과 연결

## 6. 권장 평가 구성

- 공식 ExpDate 평가 665장은 학습에 섞지 않고 기준 성능 측정용으로 유지
- 한국 매장 실사 데이터는 상품/SKU/촬영 세션 단위로 그룹 분할
- 최종 테스트에는 합성 이미지를 넣지 않고 실제 촬영 이미지만 사용
- 핵심 지표는 날짜 완전일치율, 날짜 영역 검출 재현율, 이미지당 처리시간, 실패율로 관리

## 7. 주의 사항

- 점검 도중 기존 `상품사진입니다` 폴더에 외부 작업으로 `003353`~`016977` 파일이 13,625장이 추가된 상태를 발견했다.
- 기존 폴더의 파일은 삭제·이동·수정하지 않았다.
- 실제 학습 입력을 합칠 때는 두 폴더를 단순 병합하지 말고 중복 제거 절차를 먼저 수행해야 한다.
- `004756.jpg`, `004999.jpg`, `005027.jpg`는 JPEG 원시 크기가 `2016×1512`이고 EXIF Orientation 값이 6이다. EXIF 회전을 적용한 실제 표시 크기 `1512×2016`이 공식 라벨의 크기와 일치하므로, 학습 로더에서 EXIF 회전을 적용한 뒤 바운딩 박스를 사용해야 한다.
